# Massage World News Bot — v1

Telegram-бот для мировых новостей о ручном и аппаратном массаже.

Команды:
- /start
- /news
- /digest
- /help

Возможности:
- OpenAI Responses API
- встроенный Web Search
- фильтрация рекламы и дублей
- русскоязычный анализ
- ежедневный дайджест
- SQLite для списка пользователей

Безопасность:
Никогда не публикуйте TELEGRAM_BOT_TOKEN или OPENAI_API_KEY.
Добавляйте их только как секретные переменные окружения.

Облачный запуск:
Проект рассчитан на Worker. Есть готовый render.yaml.
По умолчанию дайджест отправляется ежедневно в 09:00 по
Europe/Moscow.
